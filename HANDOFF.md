## 0. Коротко

- **Что это.** Одностраничный лендинг ТОО «Perfluence», официального
  партнёра АО «Казахтелеком»: тарифы на домашний интернет, ТВ и мобильную
  связь и приём заявок. Две языковые версии, **казахская по умолчанию**.
- **Главное требование.** Каждая заявка привязана к менеджеру (блогеру),
  который привёл клиента, по персональной ссылке `…/?manager=КОД`.
  Блогеров около 3000.
- **Заявки** принимает форма **Qbox** (`qbox.telecom.kz`), встроенная в
  страницу рамкой (iframe) в модальном окне. Менеджер, тариф и язык
  уходят ей параметрами адреса. Своего бэкенда нет.
- **Стек:** Vue 3.5 + TypeScript + Vite 8 (`<script setup>`, `vue-tsc`),
  Tailwind 4 подключён, но почти не используется — оформление на своём CSS
  с токенами. Маршрутизатора нет.
- **React в проекте запрещён** — его не пропускают на сайт Казахтелекома.
  Лендинг был на React до 16 октября 2026, переписан на Vue; последняя
  версия на React — метка `react-final` в git. Кода на React в папках нет.
- **Боевой адрес:** `https://telecom.kz/perfluence/`. КТ принимает
  **исходники** и собирает сам (`pnpm build`), см. раздел 7.
- **Витрина:** https://landing-perfluence.vercel.app — версия на Vue,
  шесть тарифов, аренда оборудования, Go Smart без выбора оператора,
  новый подвал (коммит `5b6b0dd`, 27 октября 2026). Обновлять только по
  «да» заказчика.
- **Репозиторий:** https://github.com/sadbubble/landing-perfluence
  (публичный), ветка `main`.

## 1. Запуск

```bash
npm install
```

```bash
npm run dev
```

Откроется `http://localhost:8080`. Переменные окружения не нужны.

- `/` — лендинг;
- `/?manager=test` — он же по ссылке менеджера.

**Порт 8080, а не 5173, — обязательно.** Qbox отдаёт заголовок
`Content-Security-Policy: frame-ancestors` со списком доменов, которым можно
показывать форму в рамке. Из локальных там только `8080`, `4200` и `4502`.
На 5173 рамка молча не загрузится. В `vite.config.ts` стоит
`strictPort: true`: при занятом 8080 Vite не уйдёт на 8081 (там форма тоже
не встраивается), а честно откажется стартовать.

**8080 бывает занят чужим проектом** `C:\work\internet-figma` (на
localhost:8080 тогда открывается «Figma Make App», «до 1 Гбит/с»). Порт не
менять — запускать на 4200:

```bash
npx vite --port 4200 --strictPort
```

Конфиги в `.claude/launch.json`:

| имя | что запускает |
|---|---|
| `dev` | `npm run dev`, порт 8080 |
| `dev-4200` | dev-сервер на 4200 |
| `preview-dist` | `vite preview` готовой сборки `dist/` на 4200 |
| `noslash-4200` | `scripts/serve-noslash.py` на 4200 — сервер, который, как telecom.kz, убирает слэш в конце адреса (301 `/perfluence/` → `/perfluence`). Каталог — тот же, что у `static-4200`. |
| `static-4200` | `python -m http.server 4200` — «тупой» сервер без правил, для проверки «как выложит КТ». **Путь к каталогу в нём — временная папка сессии, где собирали выгрузку (сейчас — от 23.10.2026); перед запуском поменять на свой.** |

**Язык по умолчанию — казахский.** Выбор RU/KZ хранится в `localStorage`
под ключом `perfluence.lang`; чтобы увидеть страницу «как новый
посетитель», удалите его.

## 3. Как устроена страница

Сверху вниз: плавающая шапка → баннер на высоту окна → тарифы → «Как
подключить» → нижний баннер → подвал. Одна страница, подадресов нет.

### Куда ведёт какая кнопка

| кнопка | действие |
|---|---|
| «Выбрать тариф» в шапке и в баннере, стрелка вниз | прокрутка к тарифам + подсветка секции на 1,4 с |
| «Подключить» на карточке | окно с формой Qbox **с выбранным тарифом** |
| «Оставить заявку» в нижнем баннере | окно с формой **без** тарифа |

Раньше все кнопки открывали форму, и заявки приходили без тарифа. Теперь
человек сначала выбирает тариф. Нижний баннер обещает «перезвоним и
подскажем» — он для тех, кто тарифы смотреть не хочет, поэтому форма без
тарифа там намеренно. Подсветка секции нужна потому, что с кнопки в шапке
тарифы часто уже на экране и прокрутка нулевая — нажатие выглядело
сломанным.

### Менеджер

- Код берётся из `?manager=`, а также `?ref=` и `?d=` (блогеры
  пересобирают ссылки). Хранится в `localStorage` под `perfluence.manager`.
- **Без параметра сохранённый код не стирается** (так велит ТЗ); ссылка
  другого менеджера его перебивает. Срока жизни нет — решение заказчика.
- **Регистр не меняется:** коды в Qbox строчные, `test` и `TEST` для Qbox
  разные. Когда-то стоял `toUpperCase()` — убран.
- **Допустимые символы:** латиница, цифры, `_`, `-`, от 2 до 64 символов
  (`clean()` в `dealer.ts`). Код с точкой или кириллицей **молча
  отбрасывается**, и берётся ранее сохранённый — это важно при 3000
  блогеров, если коды делают из ников (`aru.blog`). Формат кодов с
  заказчиком не согласован; поле «Менеджер» в Qbox — свободный текст:
  приходит любая строка (`asd` записался как менеджер), реестра кодов нет.
- Формат `/d/КОД` из ТЗ п.5 **убран** (решение заказчика): он требовал
  настройки сервера.

### Язык

Казахский по умолчанию, `<html lang>` и заголовок вкладки следуют за
языком. По-казахски услуга называется **«ТВ»**, не «теледидар» (это сам
аппарат, а его не продают).

## 4. Приём заявок: форма Qbox рамкой

**Лендинг не отправляет заявку сам.** Вся логика — `src/lib/qbox.ts`.

```
кнопка → окно ModalDialog → <iframe class="qbox-frame"> с формой Qbox
       → человек заполняет имя, телефон, город → лид в CRM с менеджером и тарифом
```

Проверено настоящими заявками: №13571845 (менеджер `test`, «Bereket 4 SIM
(без контракта)»), позже — «Интернет 500 (контракт 1 год)». Воронка —
«тестовая Нурдаулет», форма в Qbox называется «TEst».

### Адрес формы: «#» стоит в середине — так и надо

```
https://qbox.telecom.kz/forms/?manager=test&Product_name=…&lang=kk#/7a52f500b34f49ad8fd63599e74a2ca5?embed=true
```

- **Параметры лида — ДО «#».** ТЗ велит клеить их в конец, но всё после
  «#» — фрагмент, и `location.search` формы был бы пуст.
- **`embed=true` — ВНУТРИ фрагмента**, после идентификатора формы (так
  прислали из Qbox). Без него рамка пустая белая.
- Кодирование — `encodeURIComponent`, не `URLSearchParams` (тот кодирует
  пробел как «+»).
- Две строки запроса в одном адресе — не опечатка.

### Что уходит в форму

| параметр | откуда | заметки |
|---|---|---|
| `manager` | код из ссылки | ключ поля в Qbox — `manager` |
| `Product_name` | выбранный тариф | ключ подсмотрен в Qbox: воронка → Настройки → Поля → «тариф». **С заглавной P.** На слайде 6 инструкции `product_name` — это другая воронка, не «исправлять» |
| `lang` | язык лендинга, `kk`/`ru` | `en` не шлём. Подписи полей на KZ/EN заводятся в самой форме Qbox — пока не заведены |

### Названия тарифов для Qbox

`QBOX_PRODUCTS` в `qbox.ts`, ключ `slug|mode` или `slug|mode|sim`:

| ключ | значение в поле «ПРодукт» |
|---|---|
| `internet-200\|noContract` | Интернет 200 (без контракта) |
| `internet-500\|contract` | Интернет 500 (контракт 1 год) |
| `internet-500\|noContract` | Интернет 500 (без контракта) |
| `keremet-tv-promo\|contract` | Keremet TV PROMO (контракт 1 год) |
| `keremet-tv-2026\|noContract` | Keremet TV 2026 (без контракта) |
| `bereket\|contract\|2sim` | Bereket 2 SIM (контракт 3 года) |
| `bereket\|noContract\|2sim` | Bereket 2 SIM (без контракта) |
| `bereket\|contract\|4sim` | Bereket 4 SIM (контракт 3 года) |
| `bereket\|noContract\|4sim` | Bereket 4 SIM (без контракта) |
| `back-to-school\|contract` | Back to School (контракт 3 года) |
| `go-smart\|contract` | Go Smart (Altel/Activ, контракт 1 год) |

Это **текст, который читают люди** (менеджеры продаж, расчёт выработки
дилеров), поэтому по-русски и с режимом контракта. Каталог продуктов в Qbox
не заполняется, отсюда пометка `[unresolved_products] - …` в комментарии к
лиду — **не ошибка**. Если сочетания нет в таблице, `resolveProduct()`
вернёт `null` и заявка уйдёт без тарифа (лучше пусто, чем неправда); в
режиме разработки об этом предупреждение в консоли. Финальный список
названий по инструкции Qbox готовит маркетинг — если пришлют, меняются эти
одиннадцать строк. Названия Back to School и Go Smart придумали мы — не
согласованы. Оператора Go Smart на лендинге не выбирают, «Altel/Activ» в
названии — знак менеджеру уточнить его звонком.

### Где форма встраивается, а где нет

`canEmbedForm()` сверяет домен страницы со списком `EMBED_ALLOWED_ORIGINS`
— это **копия заголовка Qbox целиком** (25 доменов, снята 23.10.2026):
`telecom.kz`, тестовые стенды КТ `staging-srv-0.telecom.kz` и
`staging-customer.telecom.kz`, `partner.telecom.kz`, `localhost:8080/4200/4502`
и прочие сайты КТ и ismet. Сверить с текущим:

```bash
curl -sI https://qbox.telecom.kz/forms/ | grep -i frame-ancestors
```

До 23.10.2026 в нашем списке было пять доменов, и тестовых стендов в нём
не было: на стенде КТ лендинг уводил на сайт Qbox вместо окна, и заказчик
по тестовому прогону справедливо счёл это негодным для релиза. Список
закреплён тестом `src/lib/__tests__/qbox.test.ts`.

- **На разрешённом домене** — окно с рамкой.
- **На любом другом** (Vercel, `127.0.0.1`, порт 5173) — кнопка уводит на
  форму Qbox **переходом**: рамку там Qbox не пустит, и окно было бы пустым.
  Заявка доходит так же. `www.telecom.kz` в списке нет, но он переадресует
  на `telecom.kz`. Чтобы окно было и на витрине Vercel, Qbox должен
  добавить `https://landing-perfluence.vercel.app` в свой список.
- **Запасной ссылки под рамкой больше нет** (убрана по слову заказчика
  23.10.2026). Она вела на ту же форму в новой вкладке и защищала от случая,
  когда встраивание заблокирует сам сайт КТ своим CSP: окно тогда выглядит
  рабочим, но пустое, а узнать это со страницы нельзя. Теперь в этом случае
  поможет только закрыть окно — после выкладки на telecom.kz проверить
  окно глазами.
- В режиме разработки есть крючок `window.__qboxHook`: присвойте функцию —
  переход не произойдёт, адрес придёт в неё. В сборку не попадает.

### Окно и ограничения чужой рамки

**Окно (с 23.10.2026)** — по образцу окон заявки на сайте КТ
(telecom.kz/telecom-internet, страница Back to School): панель до 440px,
скругление 24px, в шапке **выбранный тариф** («Bereket 4 SIM», «Keremet TV
PROMO»; с нижнего баннера — «Оставить заявку») и крестик, под шапкой
тонкая линия, под ней наш текст `formLead` («Оставьте заявку. Наш
менеджер скоро с вами свяжется» / «Өтінім қалдырыңыз. Сізге менеджеріміз
хабарласатын болады» — как заголовок формы в окнах КТ; у нашей формы в
Qbox заголовок не показывается), ниже рамка без отступов. Фон затемнён и
размыт. **Запасной ссылки «Откройте её отдельно» нет** — убрана по слову
заказчика 23.10.2026. Название для шапки едет из карточки в
`TariffSelection.title` (на языке страницы; в Qbox не уходит). Прежнее окно
— `_archive/modal-v1/`.

- **Содержимое формы Qbox нам недоступно**: поля, кнопка «Отправить»,
  заголовок формы, шрифты, цвета, переключатель «Рус / Қаз / Eng»
  стилизуются **только в настройках формы в самом Qbox**.
- **Язык.** `lang=kk/ru` форма понимает: подписи полей на языке лендинга,
  Qbox сам дописывает `&lang=…` во фрагмент (проверено 23.10.2026). Но в
  нашей форме «TEst» **кнопка только по-казахски** («Өтінімді жіберу» и в
  русской версии), а **заголовок формы не показывается**. В окнах на сайте
  КТ другая форма Qbox: заголовок «Оставьте заявку Наш менеджер скоро с
  вами свяжется» / «Өтінім қалдырыңыз…», кнопка «Отправить» / «Жіберу», без
  переключателя языков. Это настройки формы в Qbox — переводы кнопки и
  показ заголовка заводит тот, кто ведёт форму «TEst».
- **Высота.** Форма тянется на всю высоту рамки и прижимает кнопку к низу:
  при 900px между полями и кнопкой пустота, при 400px всё помещается без
  прокрутки (замер 23.10.2026, ширина 340–420). Рамка —
  `min(440px, 100svh − отступы − шапка − текст над формой)`, не ниже 360px;
  на телефоне отступ окна от краёв 12px вместо 24 (на 320×568 рамке ровно
  403px). 40px запаса — под строки ошибок (их высоту не мерили: кнопку отправки
  настоящей формы не нажимаем). На телефоне боком (568×320) окно выше
  экрана — прокручивается затемнённый фон, крестик наверху.
- Мы не видим, загрузилась ли форма (рамка cross-origin).
- Esc не закрывает окно, пока фокус внутри формы, и Tab уводит фокус из

- **Встроенный браузер Claude** с 23.10.2026 показывает содержимое рамки на

## 8. Как проверять работу

Визуальных тестов нет; проверка — **измерениями в браузере**, не на глаз.
За проект «выглядит нормально» трижды оказывалось контрастом ниже нормы.

- **Горизонтальная прокрутка:** `scrollWidth - clientWidth` = 0 на 320,
  375, 768, 1024, 1440 — в обоих языках.
- **Высота баннера** ≤ высоты окна (размеры — раздел 6).
- **Контраст** ≥ 4.5 (крупные заголовки ≥ 3.0). Считать **через canvas**:
  залить фон и цвет в canvas и прочитать пиксель. Разбор строки цвета
  врёт — Chrome отдаёт `color-mix()` как `color(srgb 0 0.56 1 / 0.15)`.
  Контраст текста баннера — сборкой фона в canvas слоями (градиент,
  картинка `cover`, круги, вуаль), метод в `docs/hero-image.md`.
- **Цели под палец** ≥ 44px.
- **Адрес формы:** `document.querySelector('.qbox-frame').src` и ссылка
  `.qbox-fallback a`. Эталон: для всех 11 сочетаний и нижнего баннера в обоих
  языках адреса проверены (таблица в разделе 4).
- **Слепок разметки** — метод, которым проверен перенос с React на Vue:
  для каждого элемента под `#root` записать путь, координаты, размер,
  классы, собственный текст, ключевые атрибуты и стили; сохранить в
  `localStorage` (один origin — значит, можно сравнивать разные сборки на
  том же порту); снять в нескольких состояниях (страница; «Без контракта»
  + 4 SIM + «Подробнее»; открытая форма) на 5 ширинах и 2 языках; сравнить.
  Перед снимком: отключить анимации инжектом стиля, проставить
  `.reveal` → `is-visible`, **дождаться `document.fonts.ready`** (иначе
  страница мерится в запасном шрифте и «расходится» на пиксели).
- **«Как выложит КТ»:** собрать, положить `dist/` простым сервером в 2–3
  разные папки (`/perfluence/`, `/ru/perfluence/`, глубже) и проверить
  загрузку всех файлов (Resource Timing, статусы), шрифты, менеджер, форму.

`npm test` — 16 тестов: 7 на нормализацию телефонов (сейчас не
используется: телефон проверяет форма Qbox) и 9 на Qbox — список доменов
для окна, сборка адреса формы («#», `embed=true`, кодирование), названия
тарифов.

## 9. Грабли рабочего окружения

Среда: Windows, Git Bash и PowerShell, встроенный браузер Claude.

- **Окончания строк смешанные** (CRLF в большинстве файлов, LF в части).
  Правки скриптами — сохраняя окончания, иначе дифф на весь файл.
- **Heredoc в Git Bash съедает `\\`**: `"\\u00a0"` в Python-коде внутри
  heredoc превращается в `"\u00a0"`. Длинные скрипты писать файлом, а не
  heredoc; сложные кавычки в heredoc ломают разбор команды.
- **Vite может закэшировать промежуточное состояние файла**, если скрипт
  пишет его дважды подряд, — страница получает старый CSS. Писать файл
  одной записью; при подозрении — `touch` файла и перезагрузка.
- **Плавная прокрутка** (`scroll-behavior: smooth`) — скриншоты отстают от
  `scrollTo`; прокручивать с `behavior: 'instant'`.
- **Скриншоты встроенного браузера** при эмуляции окна шире панели
  показывают только часть страницы; содержимое cross-origin рамок не
  показывают вовсе.
- **Скрытая панель браузера** — `innerWidth` бывает 0; задавать размер окна
  явно перед замерами. `img.decode()` в скрытой панели может зависнуть.
- После перезагрузки страницы функции, вставленные через JS, пропадают;
  хранить их кодом в `localStorage` и вызывать `eval`.
- Python в консоли Windows — `sys.stdout.reconfigure(encoding="utf-8")`,
  иначе падает на кириллице.
