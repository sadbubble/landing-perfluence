# Лендинг Perfluence — официальный партнёр АО «Казахтелеком»

Одностраничный лендинг для сбора заявок на подключение интернета и ТВ.
Каждая заявка привязывается к дилеру, приведшему клиента.

> **Начинать читать отсюда:**
> [`STATUS.md`](STATUS.md) — что готово и что осталось ·
> [`HANDOFF.md`](HANDOFF.md) — как устроено и почему именно так ·
> [`TODO.md`](TODO.md) — список задач

## Быстрый старт

```bash
npm install
```

```bash
npm run dev
```

Откроется `http://localhost:8080` — **не 5173**. Порт выбран не случайно:
форма заявки встраивается рамкой с `qbox.telecom.kz`, а тот разрешает это
лишь с перечисленных у него адресов, и 5173 в их числе нет. Подробности —
в `vite.config.ts`.

Переменные окружения не нужны. Адреса: `/` — лендинг, `/?manager=test` —
он же по ссылке менеджера, `/d/AG-K7F21` — старый формат из ТЗ п.5,
`/privacy` — политика персданных.

## Структура

| Путь | Что там |
|---|---|
| `src/pages/Landing.tsx` | Вся страница: состояние, обработчики, порядок секций |
| `src/components/` | Секции и элементы |
| `src/content/ru.ts`, `kk.ts` | **Все тексты.** Одинаковый набор ключей в обоих |
| `src/lib/dealer.ts` | Чтение кода менеджера из адреса |
| `src/lib/qbox.ts` | **Точка подключения Qbox.** Всё про форму здесь |
| `src/index.css` | Все стили и токены оформления |
| `public/` | Картинки и шрифты |
| `_archive/` | Убранное из проекта: бэкенд, админка, экспорт Figma |
| `assets-src/fonts/` | Исходные .otf Helvetica Neue, в сборку не идут |

Два правила, на которых всё держится: **тексты только в `content/*.ts`**
(иначе рассыплется казахская версия) и **цвета только через токены в
`:root`** (иначе смена фирменного стиля превратится в перебор файлов).
