## Чем занимаемся прямо сейчас

**Настройка формы приёма заявок в Qbox.** Идёт вне кода: заполняются
заголовок и состав полей на стороне платформы.

Согласовано на данный момент:

- Заголовок: «Оставьте заявку» + подпись «Перезвоним в течение рабочего
  дня и подберём тариф»
- Обязательные поля: имя, телефон, тариф, согласие на обработку персданных
- Необязательные: город или адрес

Не решено: **куда положить код дилера** — в форме Qbox под него нет места.
Это блокирует всю затею, подробности ниже в пункте 1.

Пока форма не настроена и API неизвестен, отправка заявок с лендинга не
подключается: код к этому готов, ждёт только адреса и формата.

## Блокирует запуск

### 1. Приём заявок в Qbox

Сейчас заявка уходит в адрес, которого не существует, и форма показывает
ошибку отправки. Без этого лендинг собирать заявки не может.

**Подзадача, которая важнее самой интеграции: коду дилера в форме Qbox
некуда лечь.** В показанной форме три поля — Имя, Телефон, Город. Без
места под код дилера заявки будут обезличенными, а это главное требование
ТЗ п.5 и основа расчёта с сотрудниками. Варианты: скрытое поле, UTM-метка,
отдельная форма на дилера.

Там же нет согласия на обработку персданных — добавить обязательно.

Сначала выяснить у владельцев Qbox:
- **можно ли добавить скрытое поле** под код дилера;
- есть ли HTTP API для приёма лидов и какой формат;
- какая авторизация;
- **разрешены ли запросы из браузера** (CORS).

От последнего зависит, нужен ли обработчик на сервере КТ. Заложить это в
запрос к Казахтелекому **до того, как сервер выделят**, — иначе просить
придётся дважды. Подробности и обоснование — в [`HANDOFF.md`](HANDOFF.md).

Менять: `handleSubmit` в `src/pages/Landing.tsx`, `submitLead` в
`src/lib/api.ts`.

### 2. Сервер и домен от Казахтелекома

Ждём. Код от этого не зависит: сборка статическая, кладётся как есть.

### 3. Юридическая проверка политики персданных

Текст в `src/content/privacy.ts` — рабочая заготовка под закон РК, не
заверенный документ. Нужно:
- утверждение юриста Perfluence;
- **казахский перевод от юриста** — машинный перевод правового текста
  недопустим, а для домена КТ госязык почти наверняка обязателен.

При изменении текста поднять `PRIVACY_VERSION` и `CONSENT_VERSION`: версия
согласия пишется в каждую заявку.

### 4. Лицензия на Helvetica Neue

Шрифт коммерческий, веб-использование лицензируется отдельно. Убедиться,
что у КТ лицензия есть. Риск заказчика, но поднять его должны мы.

## Технический долг

### Завести git

Репозитория нет. Любая ошибка необратима, откатиться некуда. Сделать до
следующей крупной правки:

```bash
git init && git add -A && git commit -m "Исходное состояние"
```

### Tailwind подключён, но не используется

`@import 'tailwindcss'` в `src/index.css` и плагин в `vite.config.ts` есть,
а утилитарных классов в разметке нет ни одного — всё оформление на своих
классах и токенах. Остался от экспорта из Figma Make.

Перед удалением проверить, не держится ли вёрстка на его сбросе стилей
(preflight): если да, заменить сброс на свой.

### Панель выбора оформления

`?themes=1` показывает переключатель из четырёх тем — остался с этапа
согласования дизайна. Бренд утверждён, три альтернативные темы больше не
нужны. Удаление уберёт `ThemePicker.tsx`, `lib/theme.ts` и три блока
`[data-theme]` из CSS.

Не удалено, потому что на боевой странице панель не видна и вреда не
приносит.

### Иконки шагов весят по 100 КБ

Три PNG с прозрачностью. В WebP было бы вдвое меньше при том же качестве.
Не срочно: лежат ниже первого экрана и грузятся отложенно.
